# Generated TikZ fragments

Files in this directory are **generated by the R pipeline** under `../R/`
(`validity.R`, `xdet.R`, `process_*.R`, …).

- **Do edit:** `../R/*.R` (and frozen JSON / CSV inputs as appropriate).
- **Do not edit:** `*.tex` here by hand.
- **Regenerate:** from `../`, run `make r-data` (or the specific `Rscript` that owns the fragment).
